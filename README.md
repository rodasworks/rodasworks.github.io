# rodasworks.github.io

Portafolio de Patricio Rodas (Rodas Works).

- `contenido/proyectos.mjs`: textos, colores e imágenes de cada proyecto.
- `node build.mjs`: genera `index.html` y las páginas de `proyectos/` a partir de ese archivo.
- `assets/`: estilos, script, imágenes y tipografías (Figtree, Pixelify Sans y Caveat, todas con licencia OFL).

Sitio estático, sin dependencias externas: se publica tal cual con GitHub Pages.
